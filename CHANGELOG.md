# История изменений

## 1.0.0 — 2026-11-03

Первый публичный выпуск.

- Передача системного звука в два устройства через WASAPI.
- Независимые очереди с компенсацией дрейфа и ограничением накопления звука.
- Регулировка громкости копии и задержки во время работы.
- Выбор устройств, сохранение настроек и значок в трее.
- Временное переключение выхода Windows с восстановлением при штатной остановке.
- Автономная сборка Windows x64 со встроенным .NET 10.0.14.
- Десять детерминированных проверок движка, проверка интерфейса и GitHub Actions.
