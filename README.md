# DualAudio — «Два наушника»

[![Build and test](https://github.com/pro-007-m/DualAudio/actions/workflows/ci.yml/badge.svg)](https://github.com/pro-007-m/DualAudio/actions/workflows/ci.yml)

[Скачать последнюю версию](https://github.com/pro-007-m/DualAudio/releases/latest)

Небольшое приложение для Windows 11: один системный звук одновременно в двух устройствах вывода, например в проводных и Bluetooth-наушниках.

В основной схеме Bluetooth-наушники воспроизводят звук Windows напрямую, а DualAudio передаёт его копию в проводные. Задержку проводной копии можно подстроить на слух. Дополнительный аудиодрайвер, виртуальный кабель и Voicemeeter для этого не нужны.

## Запуск

Нужны Windows 11 x64 и два подключённых устройства воспроизведения. Готовая автономная сборка — один `DualAudio.exe` со встроенным .NET runtime: установка приложения, отдельная установка .NET и права администратора для обычного запуска не требуются.

1. Скачайте и распакуйте сборку из раздела [Releases](https://github.com/pro-007-m/DualAudio/releases), затем откройте `DualAudio.exe`.
2. В поле «Источник звука» выберите Bluetooth-наушники.
3. Для первой пары выберите проводные наушники, для второй — те же Bluetooth-наушники, что и в источнике. Названия зависят от оборудования; проверьте все три поля.
4. Оставьте галочку «Назначать источник выходом Windows на время работы» и нажмите «Включить звук в двух наушниках».
5. Нажмите «Проверить звук» или включите музыку. Отрегулируйте громкость в Windows и в приложении.

Если автоматическое переключение не сработало, снимите галочку и назначьте выбранный источник выходом Windows вручную через «Настройки Windows». Если проигрыватель использует закреплённый выход, выберите в нём системное устройство по умолчанию или нужные Bluetooth-наушники и перезапустите воспроизведение.

## Громкость и задержка

Для каждой программной копии доступны громкость 0–100% и дополнительная задержка 0–1500 мс. Их можно менять во время передачи. Если выход совпадает с источником, он играет напрямую: его громкость регулируется в Windows, а настройки копии отключены, чтобы звук не дублировался повторно.

Начальная задержка первой пары — **120 мс**. Это отправная точка, а не измерение конкретной гарнитуры. Если проводные наушники играют раньше Bluetooth — увеличьте задержку проводных; если позже — уменьшите её, вплоть до нуля. При изменении задержки возможна короткая пауза для перестройки буфера.

Bluetooth, драйверы и буферы воспроизведения имеют собственные задержки. Точное акустическое совпадение не гарантируется. DualAudio добавляет задержку, но не может убрать задержку радиоканала или воспроизвести ещё не полученный звук. Синхронизация с видео также зависит от проигрывателя и оборудования.

## Остановка и настройки

«Остановить» и закрытие окна прекращают передачу. Если приложение временно меняло выход Windows, оно пытается вернуть прежний выход. Ваш новый выбор, сделанный в Windows во время работы, сохраняется; отдельный выход для связи приложение не переключает. После принудительного завершения процесса или сбоя питания выход при необходимости нужно выбрать вручную.

Сворачивание и кнопка «В трей» прячут окно рядом с часами, сохраняя передачу. Двойной щелчок по значку возвращает окно. При ошибке устройства передача останавливается: подключите устройство, нажмите «Обновить» и включите передачу снова.

Настройки сохраняются в `%LOCALAPPDATA%\DualAudio\settings.json`. Для сброса закройте приложение и удалите этот файл. Ключ `--start` запускает передачу сразу с сохранёнными настройками:

```powershell
.\DualAudio.exe --start
```

Приложение обрабатывает звук локально: не записывает его в файлы и не отправляет по сети. Сетевой доступ и учётная запись для работы не нужны.

## Если звука нет

- Проверьте подключение, громкость, отключение звука и микшер Windows у обоих устройств.
- Убедитесь, что выбран источник, через который действительно играет музыка.
- Закройте программы, которые занимают нужное устройство в монопольном режиме.
- Для Bluetooth выберите профиль воспроизведения музыки. Использование микрофона Classic Bluetooth-гарнитуры может переключить её в телефонный профиль с другим качеством звука.
- Монопольное воспроизведение и защищённый контент могут быть недоступны для loopback-захвата.

Можно также выбрать уже установленный виртуальный выход отдельным источником, а две реальные пары — выходами. Тогда задержка и громкость регулируются для обеих копий. DualAudio сам не устанавливает и не настраивает виртуальные кабели или внешние микшеры.

## Сборка из исходников

Нужны Windows и **.NET SDK 10**. Проект: `src/DualAudio/DualAudio.csproj`, C# / WinForms, NAudio 2.2.1. Из корня репозитория:

```powershell
.\scripts\build.ps1
.\scripts\test.ps1
.\scripts\publish.ps1
```

Результаты публикации и проверок размещаются в `artifacts/`. Для восстановления NuGet-зависимостей при сборке нужен доступ к источнику пакетов.

Сборку и автономную публикацию можно выполнить напрямую:

```powershell
dotnet build .\src\DualAudio\DualAudio.csproj -c Release
dotnet publish .\src\DualAudio\DualAudio.csproj -c Release -r win-x64 --self-contained true -o .\artifacts\publish
```

Workflow релиза запускается для тегов `v*`, например `v1.0.0`. Подробности устройства приложения и проверок: [архитектура](docs/architecture.md), [валидация](docs/validation.md).
