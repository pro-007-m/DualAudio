# Участие в разработке

Нужны Windows и .NET SDK 10. Команды из корня репозитория:

```powershell
.\scripts\test.ps1 -UiSmoke
.\scripts\publish.ps1
```

Проверки движка не включают звук и не переключают устройства. Аппаратные
диагностические команды запускайте отдельно на своих устройствах; их назначение
описано в README.

Для ошибки укажите версию приложения и Windows, шаги воспроизведения, ожидаемое
и фактическое поведение. Уберите из отчётов личные имена устройств и пути.
Не прикладывайте `settings.json`, полный список устройств или аудиозаписи без необходимости.

В pull request объясните причину изменения и проверки. Если меняете зависимости
или версию runtime, обновите `packages.lock.json` и уведомления о лицензиях.
После восстановления зависимостей уведомления обновляются командой
`.\scripts\update-notices.ps1`.
